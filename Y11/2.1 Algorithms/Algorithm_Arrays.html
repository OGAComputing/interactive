Worked Example — Totalling an Array

The pseudocode below uses a for loop to iterate through every element of the array, accumulating a running total. A variable total is set to zero before the loop begins, then each element is added to it in turn. 

temperatures = [18, 22, 15, 29, 25, 12, 20]
total = 0
for i = 0 to 6
    total = total + temperatures[i]
next i
print("Total temperature this week: " + str(total) + "°C")
