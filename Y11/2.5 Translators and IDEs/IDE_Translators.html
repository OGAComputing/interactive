Q1. Explain what is meant by a high-level programming language. Give one advantage of using a high-level language over a low-level language.

[3 marks]
Mark Scheme — Q1 (3 marks)
  • Uses English-like / human-readable syntax (1)
  • Is abstracted from the hardware / programmer does not need to know how the processor works (1)
  • Advantage (any one): portable — code runs on different hardware without major changes (1) or easier/quicker to write and maintain (1) or less chance of hardware-level errors (1)

Q2. State one advantage and one disadvantage of using a compiler compared to an interpreter.

[2 marks]
Mark Scheme — Q2 (2 marks)
  • Advantage (any one): produces a standalone executable / programs run faster at execution time / source code not needed by the end user / more secure distribution (1)
  • Disadvantage (any one): errors only reported after the whole program is scanned / harder to pinpoint specific bugs / must recompile after every change (1)

Q3. Describe three tools available in an Integrated Development Environment (IDE) and explain how each one helps a programmer develop a program.

[6 marks]
Mark Scheme — Q3 (2 marks per tool × 3 tools = 6 marks)
  • Editor: allows the programmer to write and edit source code (1); features such as syntax highlighting and auto-complete reduce mistakes and speed up coding (1)
  • Error diagnostics: detects and flags errors (syntax / logic) in the code (1); shows the line number where the error occurs so the programmer can find and fix bugs quickly (1)
  • Run-time environment: allows the programmer to run and test the program without leaving the IDE (1); includes a debugger so they can step through code line by line and inspect variable values (1)
  • Translator: converts the source code into machine code automatically (1); built into the IDE so the programmer does not need a separate tool (1)
(Award marks for any three tools, 2 marks each: 1 for naming/describing the tool, 1 for explaining the benefit to the programmer.)

Q4. A developer writes a new mobile app. During development they use an interpreter. When the app is finished, they use a compiler to create the final version.
Explain why each choice is appropriate.

[4 marks]
Mark Scheme — Q4 (4 marks)
  • Interpreter during development (any two):
  • Stops and reports errors immediately on the line where they occur, making debugging easier (1)
  • The developer can test small sections of code as they write it, without waiting for a full compilation (1)
  • No need to recompile after every small change (1)
  • Compiler for the finished product (any two):
  • Produces a standalone executable that runs faster for end users (1)
  • Source code is not included / not exposed, protecting the developer's intellectual property (1)
  • Users do not need an interpreter installed to run the app (1)
