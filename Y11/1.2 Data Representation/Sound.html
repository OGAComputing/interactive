🎯 Use the file size formula to calculate the size of sound recordings.

The Formula

File size (bits) = Sample Rate (Hz) × Bit Depth × Duration (seconds)
÷ 8 → bytes  |  ÷ 1,024 → KB  |  ÷ 1,024 → MB

Step 2 — total bits (× 30 sec): bits
Step 3 — convert to bytes (÷ 8): bytes
Step 4 — convert to MB (÷ 1024 ÷ 1024): MB

Exam QuestionExplain how the sample rate and bit depth affect the quality and file size of a digital audio recording. [4]
The sample rate is how many times each second the sound is recorded. A higher sample rate makes the recording sound better because more samples are captured. Bit depth is the number of bits used per sample, which controls how precisely the amplitude is measured. Increasing the sample rate or bit depth will produce a larger file. A longer recording will also use more storage space.
