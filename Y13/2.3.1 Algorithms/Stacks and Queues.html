    Write a main program that uses the stack to reverse 10 characters.

    Scenario

    The push() and pop() functions have already been written for you and work on theStack (you do not see their code).

    A program reverses a set of data using the stack. The main program takes 10 characters, one at a time, as input from the user and uses push() to insert each one onto the stack. Once all 10 characters have been pushed, the program uses pop() to output all 10 characters.

    Your program must:

    • Loop to take 10 characters, one at a time, from the user
    • Call push() with each character as it is entered
    • Then loop to call pop() and output each of the 10 characters

    When you press Run, the test enters the characters a, b, c … j in that order. A correct program outputs them reversed: j, i, h … a.
