Show worked example — adding methods to an existing class (Vehicle)

The Vehicle class below already has a constructor. Study how getSpeed() (a function) and accelerate() (a procedure) are added, then close this panel and write your own methods for Book.

Vehicle
private make : string
private speed : integer
public new(make : string)
public getSpeed() : integer
public accelerate(amount : integer)
class Vehicle
  private make
  private speed

  public procedure new(vehicleMake)
    make = vehicleMake
    speed = 0
  endprocedure

  // ← function: returns a value, uses return
  public function getSpeed()
    return speed
  endfunction

  // ← procedure: changes state, no return
  public procedure accelerate(amount)
    speed = speed + amount
  endprocedure
endclass

v = new Vehicle("Ford")
v.accelerate(30)
print(v.getSpeed())
function … return Use function/endfunction when the method gives a value back. Always include a return statement. Private attributes are accessed by name directly inside any method.
procedure … no return Use procedure/endprocedure when the method changes state but does not return a value. Parameters work exactly the same as in standalone subroutines.
attribute access Inside a method, refer to the class's own attributes by their declared name — speed, not self.speed. OCR pseudocode handles this automatically.
