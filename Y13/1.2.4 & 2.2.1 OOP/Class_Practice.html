Declare the BankAccount class with a constructor that sets two attributes.
Show worked example — a different class (Car) for reference

The UML below describes a Car class. Study the pseudocode that implements it, then close this panel and write your own BankAccount class.

Car
private make : string
private model : string
public new(make : string, model : string)
class Car
  private make
  private model

  public procedure new(carMake, carModel)
    make = carMake
    model = carModel
  endprocedure
endclass

// Create an instance and test it
myCar = new Car("Toyota", "Corolla")
print(myCar.make)
print(myCar.model)
class … endclass Wraps the whole class definition. The class name matches the UML box header.
private attribute Each attribute shown in the UML is declared with private before the name — OCR uses encapsulation by default. No type annotation needed in pseudocode.
procedure new The constructor is always named new. Parameter names can differ from attribute names — the body assigns parameter values to attributes.
