Y8 Python Unit 1: teacher quick guide

Interactive lessons that run in the browser. Students don't need to install anything.

📮 Posting a lesson to Google Classroom

  1. One-time only: run Classroom setup so scores can sync.
  2. On the hub, click Sign in to Assign to Classroom, then pick your class (and optionally a topic).
  3. Open the Year 8 tab, find the lesson under Python Unit 1, and click ➕ Assign to Class.
  4. Students open it from Classroom and sign in. Scores arrive as draft grades for you to return.

More detail: full getting-started guide.

▶ In the lesson

  • Each lesson runs Predict → Run → Investigate → Modify → Make. Make sure students start on Predict.
  • Work saves automatically, but only on the same computer and browser.
  • If code fails, 💡 Get help explains the error. ↺ Reset undoes the current step only.

🔑 Skipping a task

After 3 failed checks on an Investigate step or Modify task, a Skip button appears. It asks for a password:

outwood

The password is the same in every lesson. A skipped task scores nothing, and the student can go Back and try it again later.

📊 The progress bar

It's the thin bar along the top of the page. Its length shows how far through the five stages the student is. Its colour tells you:

Purple/teal: on track
Amber: stuck. No progress for 8 min (10 min in Modify)
Red: a skipped task hasn't been passed yet

The score badge in the bottom-left turns green at 80% and gold at 100%.
