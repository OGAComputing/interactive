Grade sync probe

Tests whether grades can be synced without a proxy. You need a test class with a teacher account and a student account, and an assignment in it created with the hub's Assign button.

  1. In the student's browser: sign in as student, pick the assignment, click Attach probe file.
  2. In the teacher's browser: sign in as teacher, pick the same assignment, click Read submissions.
  3. If the score shows up under appProperties, click Write draft grades and check Classroom.

Assignment

Student: attach a probe file

Creates a small Drive file with appProperties.ogaScore set, attaches it to your submission, then changes the score in place (as the real evidence file would be updated).
