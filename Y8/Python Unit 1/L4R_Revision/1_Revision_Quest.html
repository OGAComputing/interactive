Build it: the cinema ticket machine
Everything together: input, variables, casting, maths and print
🎯 Write a program for a cinema. Tickets cost £7 each. Here is a sample run (the yellow parts were typed by the customer):
Sample runWhat is your name? Ava How many tickets? 3 Ava, your 3 tickets cost £21

Your program must:

  • 1Ask two questions with input(): the customer's name first, then how many tickets they want
  • 2Cast the number of tickets with int() so Python can do maths with it
  • 3Store the ticket price in its own variable, e.g. price = 7
  • 4Work out the total cost: number of tickets × the price
  • 5Print one sentence with the name and the total in it (your own wording is fine)

When you press ✓ Run & check, your program is tested with two customers: Ava buying 3, then Leo buying 5.
