Logic Gates and Truth Tables
Year 8 · Data Representation · Lesson 4
❓ How is binary logic used to represent a real-world problem?
1
Gates in real life
🎯 Use AND, OR and NOT to decide what happens in everyday situations, with 1 for yes and 0 for no.
AND, OR and NOT
  • In logic, 1 means yes (on, true) and 0 means no (off, false).
  • AND: the output is 1 only when both inputs are 1.
  • OR: the output is 1 when the inputs have at least one 1.
  • NOT: one input, and the output is the opposite.

Logic gate: makes a decision. It takes inputs of 1 or 0 and gives one output.

2
Gate symbols
🎯 Name each gate from its symbol, on its own and inside a circuit.
How to tell the symbols apart
  • AND: flat back, round front, like a letter D.
  • OR: curved back, pointed front.
  • NOT: a triangle with a small circle on its tip. It has only one input.

Drag a name onto a box, or tap a name and then tap the box. Tap a filled box to empty it.

3
Truth tables
🎯 Complete the truth tables for AND, OR and NOT, then name a gate from its table.
Truth tables
  1. List every combination of inputs. Two inputs make 4 rows: 00, 01, 10, 11 (count up in binary). One input makes 2 rows: 0, 1.
  2. For each row, use the gate's rule to work out the output.

Truth table: shows the output for every input combination.

4
Trace a circuit
🎯 In a circuit, one gate's output is the next gate's input. Work out P, the wire in the middle, then Q, the output.
Tracing a two-gate circuit
  1. Fill in P for every row: the first gate's output, using its inputs.
  2. Use P as an input to the second gate.
  3. Fill in Q, the final output, for every row.
5
Build it
🎯 Build a logic circuit for a real problem: drag in the gates and the inputs, test it with the switches, then check it.
Building a circuit
  1. Read the rule. Find the AND, OR and NOT in it, and which input each one uses.
  2. Drag a gate into each box (or tap the gate, then tap the box). A box with one input wire only fits NOT.
  3. Drag A, B or C onto each empty input circle.
  4. Flip the switches to test it: the wires carrying 1 light up, and so does the bulb.
  5. Check tries every row of the truth table. Any circuit that gives the right output on every row is right.
