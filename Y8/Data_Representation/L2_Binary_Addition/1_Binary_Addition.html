The four rules

The four rules

Binary addition works like denary column addition: right to left, carrying into the next column. In denary you carry when a column reaches 10. In binary you carry when a column reaches 2.

  • 0 + 0 = 0
  • 0 + 1 = 1
  • 1 + 1 = 0, carry 1  (2 in binary is 10)
  • 1 + 1 + 1 = 1, carry 1  (3 in binary is 11)

🔑 carry: when a column adds up to 2 or more, a 1 moves into the next column on the left. Write it above that column and add it in.

Add with 4 bits
🎯 Add two 4-bit numbers. The help fades as you go: from step 3 you write the carries yourself. Tap an answer box to set it: ? → 0 → 1. Tap a carry box to add a carry.
The method
  1. Write the two numbers in columns, one above the other.
  2. Start at the rightmost column. Add its two bits and any carry above it.
  3. Write the answer bit underneath. If the column made 2 or 3, write a carry 1 above the next column on the left.
  4. Move one column left and repeat.
4
The final carry
🎯 When the leftmost column makes a carry, the answer gets one bit longer.
The final carry
  1. Add right to left, carrying as before.
  2. If the leftmost column makes a carry, there is no column for it. Write it as a new bit on the left.
  3. So two 4-bit numbers can make a 5-bit answer: 1000 + 1000 = 10000 (8 + 8 = 16).

8 bits
🎯 The same method with 8 columns. Line the numbers up, add, then check your answer in denary.
Same method, more columns
  1. If a number is shorter than 8 bits, put 0s on the left until it has 8. The value doesn't change.
  2. Add right to left, writing every carry above the next column.
  3. Check: convert both numbers and the answer to denary. The first two add up to the answer.
