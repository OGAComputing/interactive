Year 8 · Data Representation · Lesson 1
❓ How are denary numbers represented in binary using 1s and 0s?

Binary basics
🎯 Answer 4 questions in a row. One wrong answer starts you again with new questions.
2
Binary → denary (4 bits)
🎯 Turn binary numbers into denary. The help fades away as you go: by step 4 you write the headings yourself.
The method
  1. Write the headings: 8 4 2 1
  2. Write each bit under its heading, one bit per heading.
  3. Add up the headings that have a 1 under them.
3
Denary → binary (4 bits)
🎯 Turn denary numbers into binary. Tap a bit box to set it: ? → 0 → 1.
The method
  1. Write the headings: 8 4 2 1
  2. Start at the biggest heading. Does it fit into what's left?
  3. Fits: write 1 and take it away. Doesn't fit: write 0.
  4. Move to the next heading. Carry on until nothing is left.

5
8 bits: binary → denary
🎯 The same method as Task 2, with 8 headings instead of 4.
Same method, more headings
  1. The headings keep doubling to the left: 128 64 32 16 8 4 2 1
  2. Write each bit under its heading, one bit per heading.
  3. Add up the headings that have a 1 under them.
6
8 bits: denary → binary
🎯 The same method as Task 3, with 8 headings. Every answer is written as 8 bits. Tap a bit box to set it: ? → 0 → 1.
Same method, more headings
  1. Write the headings: 128 64 32 16 8 4 2 1
  2. Biggest heading first. Fits: write 1 and take it away. Doesn't fit: write 0.
  3. Write answers as 8 bits by putting 0s on the left. The value doesn't change.
