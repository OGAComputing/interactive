Hexadecimal
Year 8 · Data Representation · Lesson 3
❓ How do I represent binary numbers with fewer digits using hexadecimal?
1
Hex digits
🎯 Turn denary numbers into hex digits and back. The table fades as you go: by step 4 it's gone.
The hex digits
  1. Hex has sixteen digits. The first ten, 0–9, are the same as denary.
  2. After 9, hex uses letters: A = 10, and each letter after it is one more, up to F = 15.
  3. So every number from 0 to 15 fits in one hex digit.

Hexadecimal (hex): a number system with sixteen digits, 0–9 then A–F.

2
4-bit binary → hex
🎯 Turn 4 bits of binary into one hex digit: binary to denary with 8 4 2 1, then denary to hex. Every answer is a letter, A–F.
4-bit binary → hex
  1. Write the headings 8 4 2 1 above the 4 bits.
  2. Add up the headings that have a 1 under them.
  3. 0–9 stay the same. 10–15 become a letter: A B C D E F.

Key fact: one hex digit stands for exactly 4 bits, from 0000 (0) to 1111 (F).

3
8-bit binary → hex
🎯 Write 8 bits as 2 hex digits. From step 3 you split the bits yourself; by step 4 it's just the answer.
8-bit binary → hex
  1. Split the 8 bits down the middle into two groups of 4.
  2. Convert each group of 4 to denary using 8 4 2 1.
  3. Turn 10–15 into A–F.
  4. Join the two digits, first group first: 1011 0101 → B and 5 → B5.
4
Hex → 8-bit binary
🎯 Write 2 hex digits as 8 bits. Every hex digit gets all 4 bits, so small digits start with 0s.
Hex → 8-bit binary
  1. Take each hex digit on its own. Turn a letter into its denary value (A = 10 … F = 15).
  2. Write each value as 4 bits under 8 4 2 1, with 0s on the left if needed: 3 → 0011.
  3. Join the two groups of 4: B5 → 1011 and 0101 → 10110101.
