Detailed Breakdown of Types

1. Fill in the Blanks (Gap Fill)

The most versatile type, appearing in three main variants:

  • Drag and Drop: Used for terminology and legislation facts.
  • Dropdown Selection: Used for complex sentences where technical precision is required.
  • Click-to-Place: A streamlined variant used in Cybersecurity and Impacts.

2. Pseudocode Verification

A core part of the Paper 2 preparation. These activities use a custom pseudocode-transpiler.js to run OCR-standard pseudocode and verify it against hidden test cases, providing instant mark-scheme style feedback.

3. Scenario Classification

Highly effective for Paper 1 (Social, Ethical, Legal). Students sort scenarios into categories like "Ethical Issue" or "Malware Type". Most use a visual drag-and-drop interface with instant red/green feedback.

Suggestions for New Activity Types

To further enhance active revision, the following interactive HTML activities are suggested:

  • Parson's Problems A variation of coding challenges where students drag pre-written lines of code into the correct order. This helps focus on logic and structure without syntax frustration.
  • Interactive Trace Tables A grid where students must fill in variable values step-by-step as an algorithm executes. This directly prepares them for trace table questions in the exam.
  • Logic Gate Simulator A "builder" style activity where students connect AND, OR, and NOT gates to produce a specific boolean output, helping them visualize truth tables.
  • Hotspot Diagrams An image-based activity where students must click on specific parts of a hardware component (e.g., a motherboard or the inside of a hard drive) to identify them.
  • Data Representation Visualizers Practice tools for converting between Binary, Hexadecimal, and Denary, including "bit-flipping" games to understand place values and overflows.
  • "Pick the Odd One Out" A rapid-fire game where students identify which of 4 terms doesn't belong (e.g., three input devices and one output device) and must select the correct reason why.
  • Timed Flashcard Recall A high-pressure recall mode where students must type the definition of a keyword before a timer runs out, useful for building "fluency" in key terms.
  • Interactive Flowchart Builder A drag-and-drop canvas for building flowcharts using standard symbols (Process, Decision, I/O), mapping to the algorithm section of the specification.
  • SQL Query Builder A visual tool for selecting SELECT, FROM, and WHERE clauses from blocks to query a mock database table.
  • "Fix the Bug" (Visual) A variant of coding challenges where a working algorithm is shown but with 1-3 specific bugs. Students must click the offending line and select the correct replacement from a list.
