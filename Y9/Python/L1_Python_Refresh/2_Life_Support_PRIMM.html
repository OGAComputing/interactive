Remind me: input(), int() and +
  • input("…") shows the question, waits for the user to type, then gives back what they typed — always as text.
  • int(…) turns text like "6" into the whole number 6, so you can do maths with it.
  • = stores the value on the right in the variable on the left.
  • + between two pieces of text joins them: "Hi " + "Sam" gives Hi Sam
