Remind me: input(), variables and +
  • input("…") shows the question, waits for the user to type, then gives back what they typed.
  • = stores the value on the right in the variable on the left, so name = input(…) keeps the answer in name
  • Words in quotes are printed exactly as written. A variable name with no quotes prints what is stored inside it.
  • + between two pieces of text joins them: "Hi " + "Sam" gives Hi Sam
