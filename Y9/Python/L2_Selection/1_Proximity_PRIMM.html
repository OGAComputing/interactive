How if / else works

  1. if is followed by a condition, which is either True or False, then a colon :
  2. The indented lines under it run only when the condition is True.
  3. else: has no condition. Its indented lines run when the condition was False.
  4. Exactly one of the two blocks runs. A line back at the left edge runs every time, after them.

>= means "more than or equal to", so 50 >= 50 is True. > means "more than", < "less than", <= "less than or equal to", and == "is equal to".

How elif works

  1. elif means "else if": another condition, checked only if every condition above it was False.
  2. Python checks the conditions from the top. The first True one runs its block, and the rest are skipped, even if they are True too.
  3. else runs only when none of the conditions were True.
