How while works

  1. Set up the variable before the loop: line 1 asks for the first code.
  2. while is followed by a condition, then a colon : Python checks it at the top, before every pass.
  3. The indented lines run while the condition is True. Then Python goes back to the top and checks again.
  4. Something inside must change the variable (line 4), or the condition stays True and the loop never ends.

!= means "is not equal to", so "1234" != "4271" is True, and "4271" != "4271" is False. A while is an if that keeps checking.

Remind me: why does a loop never end?
  • A while loop stops only when its condition becomes False.
  • The condition is about code. If nothing inside the loop changes code, it stays wrong, and the condition stays True forever.

  • Running a loop that never ends? In your editor, Python stops it after 4 seconds. In other Python editors, press Ctrl+C.

Remind me: why str()?
  • + can join text to text, or add a number to a number, but it can't do both at once.
