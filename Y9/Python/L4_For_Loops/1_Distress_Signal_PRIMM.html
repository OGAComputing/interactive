How for works

  1. for i in range(4): repeats the indented lines 4 times.
  2. Each time round, i holds the next number: 0, 1, 2, 3. range() starts at 0 and stops before the number you give it.
  3. The indented lines are the loop. The first line back at the left edge runs once, after the loop.

Remind me: what range() counts
  • range(4) counts 0, 1, 2, 3: it starts at 0 and stops before 4.
  • range(1, 6) counts 1, 2, 3, 4, 5: it starts at the first number and stops before the second.
  • ★ range(0, 10, 2) counts 0, 2, 4, 6, 8: the third number is the step, how much it goes up by.

Remind me: working out the turn
  • To get back to where it started, the turtle turns a full turn, 360°, altogether.
  • It turns once at every corner, so each turn is 360 ÷ the number of sides. A square: 360 ÷ 4 = 90.
