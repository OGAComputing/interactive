How functions work

  1. def drone_status(): defines a command: a name for the indented lines under it. Python remembers them, but doesn't run them yet.
  2. drone_status() calls the command: Python jumps up, runs the indented lines, then carries on after the call.
  3. Define it first, then call it as many times as you like. The brackets () make it a call.
